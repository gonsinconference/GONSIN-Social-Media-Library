# GONSIN Social Media Library

[Open the customer library](https://gonsinconference.github.io/GONSIN-Social-Media-Library/)

[Open the Spanish social media section](https://gonsinconference.github.io/GONSIN-Social-Media-Library/?section=spanish)

This repository contains the published HTML, CSS, JavaScript, images, fonts, and customer Excel download. GitHub Pages serves these files from the root of the main branch.

For a new release, copy the updated customer-facing site files and workbook to the repository root. Keep the original Marketing Log with the working files. Keep the canonical and preview image URLs pointed at this GitHub Pages address.

The Spanish section uses `catalog-es.js` and `GONSIN-Spanish-Social-Media-Library.xlsx`. Refresh both from the `ES-Social Media` tab when a new Spanish marketing log arrives.

The bundled fonts, SheetJS, and Bootstrap Icons include their license files.
