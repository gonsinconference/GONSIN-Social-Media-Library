How to use the library

Find official GONSIN resources, share links and download a customized Excel list.

←Back to the library
  1. Choose a language
  2. Find resources
  3. Open and share
  4. Download Excel
1

Choose a language

  • Open Spanish social media or French social media from the library header to browse posts in that language.
  • The language menu changes the interface and this guide. When a library page offers to open a language section, you can go there or keep browsing.
  • In a language section, use the left-arrow button at the top to return to the English library.
2

Find resources

  • In Browse the library, enter a title keyword or product model.
  • Combine year, platform and category filters. Select Clear filters to start over.
  • Open the Newsletter or Case Studies highlight to jump to its category.
3

Open and share

  • Choose a platform button on a resource card to open the original post or file. Select the title to view the resource details.
  • Use the link icon on the card to copy that resource’s link.
  • Use Share library in the header to copy the address of the library you’re viewing.
4

Download Excel

  • Select Download Excel in the library to open the download options.
  • Set a start date, an end date or both. Select Type and Link types to refine the export. Leave a group unchecked to include all its options.
  • Select Download selection for filtered records. Download all exports the entire library you’re viewing.
  • Open the original posts and files using the clickable links in the downloaded workbook.
